# Memory

What Claude knows about the creator and how they want their videos edited, as plain files in the studio, so every chat, tool and computer works from the same notes. (Claude Code's own memory stays on one computer; these files travel with the studio.)

- `preferences.md`: how the creator wants edits done. One line per preference, in their words, dated.
- `style.md`: brand and style facts: fonts, colours, logo, the look, sound.
- Add a new file only for a new subject (for example `channel.md` for who the videos are for). Keep one subject per file.
- Claude adds a line when the creator states something lasting. Nobody adds guesses, and lines are only removed when the creator says so.
