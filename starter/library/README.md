# Library

Reusable things for every project. Video Octopus's Library page (Home → Library) shows the folders it knows; Claude reads the same `INDEX.md` lists. Every file gets one line in its folder's `INDEX.md`: what it is, where it came from, its licence, the date.

- `brand/`: logo files, fonts you may use, colour swatches. The facts (which font, which hex) go in `memory/style.md`.
- `backgrounds/`: backgrounds for layouts and scenes: images, videos, or code that draws one.
- `sfx/`: sound effects approved for use. New finds wait in `sfx/_new/` until the creator approves them.
- `styles/`: styles made from sample videos (`<name>.md`: hook, pacing, layouts, captions, sound, CTA). A Short can follow one.
- `components/`: reusable scene pieces: cards, titles, windows, lower thirds.
- `broll/`: clips to cut in over the voice.
- `stills/`: frames saved from renders.
- `resources/`: reference material: links, notes on tools, sample scripts, anything Claude should know about but not show.
