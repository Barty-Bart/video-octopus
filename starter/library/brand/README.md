# Brand

The creator's brand files, in one folder each: `logos/` (SVG or PNG with transparency), `photos/` (of the creator, for thumbnails and cut-outs), `products/` (real product images), `fonts/` (font files they may use) and `examples/` (videos and thumbnails whose look they like). Video Octopus's Setup and Settings → Brand add them, with one line each in `INDEX.md` (what it is, where it came from, the date).

`BRAND.md` in the studio folder sums them up with the creator's answers, colours and fonts; facts added later (which font for titles, which hex is the accent) go in `memory/style.md`.
